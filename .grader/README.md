# Carpeta del corrector

Aquí están las pruebas de la práctica (`tests.json`) y el programa que las pasa (`engine.py`).
`check.py` las usa para que compruebes tus ejercicios en tu ordenador.

No cambies nada de esta carpeta. Cuando entregas, el corrector de la asignatura usa la versión
original de estos ficheros, no la de tu repositorio.
